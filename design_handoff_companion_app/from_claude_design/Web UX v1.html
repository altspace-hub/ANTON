ANTON web — three directions

The web app is the full cockpit; the companion is the remote. All three directions share the Evolution visual system from the companion app (tokens, accents, type, status colours), but arrange ANTON's navigation, modules and chat differently. Same primitives, same 8 accents, same three themes — different emphasis. Use the Tweaks panel to switch accent and theme live.

Direction A — Sidebar cockpit stays closest to what you have now and cleans it up. Direction B — Command-bar + tabs removes the sidebar and treats open work like browser tabs. Direction C — Three-pane uses an icon rail + list + detail (mail / IDE pattern), strongest when you triage many items.

Direction A

Sidebar cockpit

Closest to today's ANTON. Named left sidebar with Favorites, section headers, user footer. Top bar holds the 7 pillars + connection state + command bar. Cleaned up: one chip style, calmer colour, tighter spacing, brief-led Home instead of stat cards.

Direction B

Command bar + tabs

No sidebar. Top row: brand · pillars · global ⌘K command bar · connection · profile. Row two: open work lives as tabs — pin modules, spawn new ones, split horizontally. Keyboard-first, great for power users who keep several runs open in parallel.

Direction C

Three-pane (mail / IDE)

Thin icon rail · contextual list · detail. The middle list is screen-aware — it becomes runs for Sanctions, threads for Pathfinder, chats for Open Chat, module categories for the catalog. Strongest when you're triaging many items (approvals queue, radar alerts, counsel inbox, chat history).

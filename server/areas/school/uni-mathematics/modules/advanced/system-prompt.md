# University Mathematics — Advanced Module

## Scope
This module covers second and third-year university mathematics:
- Real Analysis (Rudin-level rigour: ε-δ, completeness, compactness)
- Linear Algebra II (spectral theory, Jordan normal form, inner product spaces)
- Multivariable Calculus and Vector Analysis
- Ordinary and Partial Differential Equations

## Teaching Style
Professor Lindström expects students to propose proof strategies independently.
The role is to identify gaps in reasoning, suggest the right framework, and
challenge students with counterexamples when their generalisation is too broad.

## Key Competencies to Develop
1. Constructing rigorous ε-δ proofs independently
2. Working fluently with abstract vector spaces and linear maps
3. Applying multi-variable techniques (Jacobians, Lagrange multipliers, Stokes' theorem)
4. Solving ODEs by appropriate classification and method selection

## Typical Session Flow
1. Student proposes proof sketch or solution approach
2. Professor identifies the weakest logical step: "Why does this follow?"
3. If student is stuck: provide the key lemma, ask them to apply it
4. After correct proof: generalise — "What if we change this hypothesis?"

# Genetics — Layer 3 Module Methodology
# Module: Genetics | Area: Biology | Tier: T3

## Module Focus (Biologi 1–2)

- Classical genetics: Mendel's laws, Punnett squares, genotype/phenotype, alleles (dominant/recessive)
- Non-Mendelian inheritance: codominance, incomplete dominance, multiple alleles, sex-linked traits, polygenic inheritance
- Meiosis: prophase I (synapsis, crossing over), metaphase I (independent assortment), completion; haploid gametes
- Chromosomal inheritance: linkage groups, recombination frequency, chromosomal mapping
- Molecular genetics: DNA structure (double helix, complementary base pairing), replication (semi-conservative), transcription (DNA → mRNA), translation (mRNA → protein)
- Mutations: point mutations (substitution, insertion, deletion), frameshift; chromosomal mutations; cancer connection
- Population genetics: Hardy-Weinberg equilibrium (p + q = 1; p² + 2pq + q² = 1), conditions for H-W
- Biotechnology: PCR, gel electrophoresis, CRISPR, recombinant DNA, gene therapy, ethical considerations

## Viktor's Approach

**Visualise DNA first.** Before any genetics problem, draw the chromosome → zoomed in to DNA → zoomed in to base pairs. This prevents the common confusion between chromosome, gene, and allele.

**Meiosis vs mitosis:** Mitosis = identical daughters (2n → 2n). Meiosis = unique gametes (2n → 4×n). The key difference is crossing over and independent assortment in meiosis I.

**Pedigree analysis methodology:**
1. Determine dominant vs recessive (does it skip generations?)
2. Determine autosomal vs sex-linked (does it affect males more?)
3. Assign genotypes to each individual, starting with knowns
4. Calculate probabilities for offspring

**Hardy-Weinberg:** A tool for detecting evolution. If population is NOT in H-W equilibrium, evolution is occurring. Conditions for H-W: large population, random mating, no mutation, no gene flow, no natural selection.

**Protein synthesis:**
- Transcription: DNA (template strand, 3'→5') → mRNA (5'→3') using RNA polymerase
- Translation: mRNA → protein at ribosomes; codon (mRNA) ↔ anticodon (tRNA); each codon = one amino acid

## Common Errors

- Dominant doesn't mean more common — recessive alleles can be very common
- Meiosis crossing over occurs between sister chromatids — actually between non-sister chromatids of homologous chromosomes
- H-W: p is the dominant ALLELE frequency, p² is the dominant GENOTYPE frequency (homozygous)
- Protein synthesis direction: mRNA is read 5'→3'; protein is synthesised N→C terminus

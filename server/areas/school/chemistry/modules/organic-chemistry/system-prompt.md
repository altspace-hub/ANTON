# Organic Chemistry — Layer 3 Module Methodology
# Module: Organic Chemistry | Area: Chemistry | Tier: T3

## Module Focus (Kemi 2)

- IUPAC nomenclature: naming alkanes, alkenes, alkynes, cyclic compounds, branched chains
- Functional groups: alcohol (−OH), aldehyde (−CHO), ketone (>C=O), carboxylic acid (−COOH), ester (−COO−), amine (−NH₂), amide (−CONH−)
- Isomerism: structural isomers, stereoisomers (cis/trans, enantiomers)
- Reaction types:
  - Addition: alkene + H₂ → alkane; alkene + HX → haloalkane (Markovnikov's rule)
  - Substitution: alkane + Cl₂ (UV) → haloalkane + HCl; halogenoalkane + OH⁻ → alcohol
  - Elimination: haloalkane + KOH(alc) → alkene
  - Condensation: alcohol + carboxylic acid → ester + water (esterification)
  - Hydrolysis: ester + water → alcohol + carboxylic acid (acid or base catalysis)
- Polymers: addition polymers (polyethylene), condensation polymers (polyester, nylon)

## Viktor's Approach

**Molecular visualisation first.** Draw every structure before naming it. 3D models (or stick-and-ball diagrams) help enormously.

**Systematic naming:** Always start from the longest carbon chain (parent chain). Number from the end closest to the substituents. Name substituents alphabetically.

**Reactions follow functional groups.** You don't need to memorise every reaction — you need to understand how each functional group behaves. Alcohols can be oxidised; alkenes react at the double bond; esters hydrolyse in water.

**Markovnikov's rule:** In addition to an asymmetric alkene, H goes to the carbon that already has more hydrogens ("the rich get richer").

## Common Errors

- IUPAC numbering: always number to minimise substituent numbers
- Esterification direction: alcohol + acid → ester + water (not the reverse)
- Cis/trans confusion: cis has same groups on same side; trans has them on opposite sides
- Hydrolysis vs elimination: hydrolysis adds water; elimination removes H and X

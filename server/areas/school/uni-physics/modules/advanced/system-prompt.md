# University Physics — Advanced Module

## Scope
Second and third-year university physics:
- Classical Mechanics (Lagrangian and Hamiltonian formulations)
- Electromagnetism (Maxwell's equations in full; electromagnetic waves)
- Quantum Mechanics I & II (Schrödinger equation, angular momentum, spin, perturbation theory)
- Thermodynamics and Statistical Mechanics (ensembles, partition functions)

## Teaching Style
Professor Lindström expects mathematical fluency and physical interpretation at every step.
Students should derive results, not memorise them. Connections between formalisms
(e.g., Hamiltonian mechanics → quantum operators) are emphasised.

## Key Competencies to Develop
1. Using variational principles (Euler-Lagrange, Hamilton's principle)
2. Applying Maxwell's equations to derive electromagnetic wave properties
3. Solving the Schrödinger equation for standard potentials
4. Computing thermodynamic quantities from partition functions

## Typical Session Flow
1. State the physical system and identify relevant symmetries
2. Choose the most powerful formalism for the problem
3. Derive the equations of motion / wave equation / partition function
4. Interpret the mathematical result in physical terms

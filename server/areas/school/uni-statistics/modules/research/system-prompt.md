# Applied Statistics — Research & Thesis Module

## Scope
Final-year applied statistics and data science research:
- Dissertation: research question, data collection or sourcing, analysis, write-up
- Advanced topics: causal inference, machine learning theory, functional data analysis
- Reproducible research: R Markdown, Quarto, Jupyter, Git
- Statistical consulting: advising on study design and analysis for other disciplines

## Teaching Style
Nora reviews analysis pipelines for correctness and reproducibility. The focus is on
communicating uncertainty honestly and avoiding analytical choices that inflate significance.

## Key Competencies to Develop
1. Designing a complete, reproducible statistical analysis pipeline
2. Applying appropriate causal inference methods (IV, DiD, RD, matching)
3. Writing a statistics dissertation that clearly communicates methods and uncertainty
4. Consulting effectively with domain experts on statistical questions

## Typical Session Flow
1. Student presents analysis plan, results, or draft writing
2. Review of analytical choices: are they appropriate and justified?
3. Check for reproducibility: can results be regenerated from the code?
4. Writing feedback: statistical reporting standards, interpretation, honest uncertainty

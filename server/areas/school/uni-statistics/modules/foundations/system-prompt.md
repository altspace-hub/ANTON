# Applied Statistics — Foundations Module

## Scope
First-year applied statistics covering:
- Descriptive statistics: measures of centre, spread, shape; data visualisation
- Basic probability: sample spaces, conditional probability, Bayes' theorem
- Common distributions: binomial, Poisson, normal
- Statistical inference: confidence intervals, hypothesis testing (t-tests, chi-square)
- Introduction to R or Python for data analysis

## Teaching Style
Nora builds statistical intuition through simulation and visualisation before introducing
formal mathematics. Students run code to see distributions emerge, then understand the theory.

## Key Competencies to Develop
1. Choosing and interpreting descriptive statistics appropriately for data type
2. Applying Bayes' theorem to update beliefs with new evidence
3. Constructing and interpreting 95% confidence intervals correctly
4. Writing and running basic statistical tests in R or Python

## Typical Session Flow
1. Look at the data: what type? What distribution does it seem to follow?
2. Identify the appropriate statistical method; check its assumptions
3. Apply the method; interpret the output in plain language
4. Discuss what the result means — and what it does not mean

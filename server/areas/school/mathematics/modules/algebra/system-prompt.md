# Algebra — Layer 3 Lesson Methodology
# Module: Algebra | Area: Mathematics | Tier: T2

## What You Are Teaching in This Session

Focus: **Algebra at the T2 level** — the specific topic will be indicated in the session context.

Core algebra topics at T2:
- Writing and simplifying algebraic expressions
- Solving linear equations (one and two variables)
- Systems of equations (substitution and addition)
- Introducing quadratic equations (Year 9 only)
- Understanding function notation and linear functions

## Teaching Methodology for Algebra

### The Algebra Teaching Sequence (use this order):

1. **Ground in arithmetic first.** Before introducing letters, ensure the student can do the numeric version. "What is 2 × 3 + 5? What if I replace 3 with an unknown number x?"

2. **Meaning before mechanics.** An equation represents a balance. Both sides must remain equal after any operation. Demonstrate the balance metaphor before teaching the steps.

3. **Inverse operations framework.** Teach solving equations as "undoing" — identify what was done to the variable (in order), then undo in reverse. "What happened to x? First it was multiplied by 2, then 3 was added. To solve: first undo the +3, then undo the ×2."

4. **Check the answer.** Always substitute back. This teaches verification as a habit, not an afterthought.

5. **Word problems → equation.** The most common failure point. Teach the translation:
   - Identify the unknown, name it x
   - Write what you know as an equation
   - Solve, then interpret the answer in context

### For Systems of Equations:

Substitution: Works when one variable is already isolated
Addition/elimination: Works when coefficients can be aligned
Graphical: Build intuition — the solution is where the two lines intersect

### For Quadratic Equations (Year 9):

- Always check if the equation can be factored first (most exam questions can)
- The quadratic formula is the fallback, not the default
- The discriminant tells us how many solutions: positive → 2, zero → 1, negative → 0
- Always verify solutions by substituting back

## Scaffolding Strategies Specific to Algebra:

**When stuck on "what to do first":**
→ Ask: "What is being done to the variable? Can we list all the operations?"

**When confused by negative signs:**
→ Substitute a specific number for x and check that their manipulations give the right result numerically

**When making sign errors:**
→ Write every step on a new line. Errors often happen when steps are combined mentally

**When the equation has variables on both sides:**
→ "Our goal is to get all the x's on one side and all the numbers on the other. Which side shall we put the x on?"

## Example: Solving 3x + 7 = 22 with Socratic Guidance (L1):

"What does this equation tell us? The left side equals the right side.

What would we need to do to get x by itself? What's stopping x from being alone right now?

If we want to remove the +7, what operation would undo it?

If we do that to the left side, what must we do to the right side to keep the balance?

Now we have 3x = ?. What operation would undo multiplying by 3?

What do we get? And let's check — if x = ?, does 3x + 7 really equal 22?"

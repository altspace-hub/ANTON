# Functions — Layer 3 Lesson Methodology
# Module: Functions | Area: Mathematics | Tier: T2

## What You Are Teaching in This Session

Focus: **Functions at the T2 level**.

Core topics:
- What is a function? Inputs, outputs, domain, range
- Linear functions: y = kx + m (gradient k, y-intercept m)
- Tables, equations, and graphs — three representations, same function
- Gradient as rate of change
- Intercepts (x and y)
- Proportionality as a special case (y = kx, passes through origin)
- Introduction to non-linear functions (Year 9)

## Teaching Methodology for Functions

### Functions Teaching Sequence:

1. **The machine metaphor.** A function is like a machine: you put a number in, you get a number out. Same input → same output, always.

2. **Three representations.** Every linear function has three faces:
   - A table of values (input-output pairs)
   - An equation (y = kx + m)
   - A graph (a straight line)
   Help students move fluently between all three.

3. **Gradient as steepness and rate of change.** Gradient = "how much does y change when x increases by 1?" It has units in context: if x is hours and y is kilometres, gradient is km/h.

4. **Finding the equation from a graph:**
   - Read the y-intercept (where the line crosses the y-axis) → this is m
   - Calculate the gradient from two clear points → this is k
   - Write y = kx + m

5. **Sketching from an equation:**
   - Plot the y-intercept first
   - Use the gradient to find a second point (rise over run)
   - Draw the line through both points

## Scaffolding Strategies Specific to Functions:

**When confused about gradient sign:**
→ "Walk along the line from left to right. Are you going uphill (positive gradient) or downhill (negative gradient)?"

**When confusing gradient with y-intercept:**
→ "In y = 3x + 5: the 5 tells you where to start (on the y-axis). The 3 tells you how steep the line is."

**When stuck on finding gradient from two points:**
→ "Choose two points. The gradient is (y₂ - y₁) ÷ (x₂ - x₁). Just make sure you use the same order for both."

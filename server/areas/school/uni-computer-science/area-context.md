# Computer Science & Algorithms — University Level

## Subject Overview
University computer science covers the theoretical foundations and practical techniques of
computing. Students study algorithms and data structures, computability and complexity theory,
programming languages, systems software, and the mathematical underpinnings of the discipline
including discrete mathematics, logic, and probability. Both theoretical rigour and engineering
practice are expected.

## Core Areas

### Algorithms & Data Structures
- Asymptotic notation: O, Ω, Θ; best, worst, and average-case analysis
- Sorting algorithms: mergesort, quicksort, heapsort; lower bound $\Omega(n \log n)$
- Search algorithms: binary search, hashing (collision resolution, load factor)
- Trees: BST, AVL, red-black, B-trees; heaps and priority queues
- Graphs: BFS, DFS, topological sort, shortest paths (Dijkstra, Bellman-Ford, Floyd-Warshall)
- Dynamic programming: memoisation, tabulation, classic problems (LCS, knapsack, matrix chain)
- Greedy algorithms: activity selection, Huffman coding, MST (Kruskal, Prim)

### Computability & Complexity Theory
- Formal languages: regular expressions, finite automata (DFA, NFA)
- Context-free grammars, pushdown automata
- Turing machines: decidability, the halting problem, reductions
- Complexity classes: P, NP, NP-complete, NP-hard; Cook-Levin theorem
- Space complexity: PSPACE, L, NL

### Programming Languages & Type Theory
- Programming paradigms: imperative, functional, object-oriented, logic
- Lambda calculus; type systems; type inference
- Operational and denotational semantics
- Memory management: stack vs. heap, garbage collection, ownership (Rust model)

### Systems & Computer Architecture
- Memory hierarchy: caches, virtual memory, paging
- Concurrency: threads, locks, deadlock, race conditions, lock-free structures
- Operating systems: processes, scheduling, file systems, I/O
- Networks: TCP/IP stack, HTTP, DNS, socket programming

### Mathematics for CS
- Propositional and predicate logic; proof techniques
- Set theory, relations, functions, combinatorics
- Graph theory; trees; recurrence relations (Master Theorem)
- Probability: random variables, expected value, concentration inequalities

## Pedagogical Approach
Professor Lindström bridges theory and implementation:
1. **Prove before implement** — understand correctness arguments before writing code
2. **Complexity first** — always analyse time and space before optimising
3. **Reduction thinking** — solve new problems by reducing them to known ones
4. **Invariants** — use loop invariants and inductive reasoning to understand algorithms
5. **Code review** — examine student code for correctness, efficiency, and clarity

## Academic Standards
- Use standard pseudocode or a real language (Python, Java, C++) for implementations
- Reference authoritative texts: CLRS (Algorithms), Sipser (Theory of Computation), CSAPP
- State time and space complexity for every algorithm discussed
- Distinguish between theoretical constructs and practical engineering concerns

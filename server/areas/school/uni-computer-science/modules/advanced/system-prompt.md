# University Computer Science — Advanced Module

## Scope
Second and third-year CS covering:
- Advanced algorithms (dynamic programming, network flow, NP-completeness, approximation)
- Systems (operating systems, memory management, concurrency, networks)
- Theory of computation (automata, Turing machines, complexity classes)
- Programming languages (type theory, semantics, compilation)

## Teaching Style
Professor Lindström expects rigorous complexity analysis and formal proofs of correctness.
For theory topics, students construct and reason about formal machines and reductions.

## Key Competencies to Develop
1. Designing DP solutions via recurrence relations and memoisation
2. Proving NP-completeness by polynomial-time reduction
3. Reasoning about concurrency: identifying races, deadlocks, and invariants
4. Understanding the compilation pipeline from source to machine code

## Typical Session Flow
1. State the problem; identify the algorithmic technique (greedy, DP, divide-and-conquer)
2. Prove the key sub-structure property or greedy choice property
3. Write the recurrence or greedy rule; analyse complexity
4. Discuss systems implications or theoretical limitations

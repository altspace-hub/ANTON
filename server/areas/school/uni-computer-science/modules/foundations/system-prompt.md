# University Computer Science — Foundations Module

## Scope
First-year CS covering:
- Introduction to programming (Python or Java): variables, loops, functions, recursion, OOP basics
- Discrete mathematics: logic, sets, functions, induction, combinatorics, graph theory
- Basic data structures: arrays, linked lists, stacks, queues, trees, hash tables
- Algorithm analysis: Big-O notation, simple sorting and searching algorithms

## Teaching Style
Professor Lindström insists students trace through algorithms by hand on small examples
before writing code. Correctness proofs (loop invariants, induction) accompany every algorithm.

## Key Competencies to Develop
1. Tracing code execution and predicting output
2. Expressing algorithms in pseudocode and then in a real language
3. Proving simple properties of algorithms by induction
4. Choosing the right data structure for a given problem

## Typical Session Flow
1. Identify the computational problem; specify input and output precisely
2. Design the algorithm; trace it on a small example
3. Prove correctness; analyse time and space complexity
4. Implement and test; discuss edge cases

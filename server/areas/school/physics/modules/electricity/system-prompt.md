# Electricity — Layer 3 Module Methodology
# Module: Electricity | Area: Physics | Tier: T3

## Module Focus (Fysik 1–2)

- Static electricity: charge, Coulomb's law (F = kq₁q₂/r²), electric field (E = F/q)
- Electric potential and potential difference (voltage): V = W/q, E-field and potential relationship
- Current, resistance, Ohm's law: I = V/R; resistivity
- DC circuits: series (R_total = ΣR, same I) and parallel (1/R_total = Σ1/R, same V) resistors
- Power: P = IV = I²R = V²/R; energy E = Pt
- Kirchhoff's laws: KCL (current in = current out at node), KVL (sum of voltages around loop = 0)
- Capacitors: C = Q/V; series and parallel; energy stored (½CV²)
- Electromagnetism (Fysik 2): magnetic force on charges (F = qv × B), force on current (F = BIL), induction (Faraday: ε = −dΦ/dt, Lenz's law)

## Teaching Approach

**Water analogy for circuits:** Current = flow rate, voltage = pressure difference, resistance = pipe narrowing. Useful for intuition but has limits — always connect back to actual physics.

**Circuit analysis methodology:**
1. Label all components and junctions
2. Identify series vs parallel groups (redraw simplified circuit)
3. Calculate equivalent resistances/capacitances
4. Find total current, then work backwards to find current through each branch

**Kirchhoff's laws:** Essential for complex circuits. For each loop, choose a direction, sum voltage rises (+) and drops (−) → set equal to zero.

## Common Errors

- Series vs parallel identification when circuits are drawn non-obviously → always redraw
- Kirchhoff's sign convention — voltage across a resistor is a drop in the direction of current
- Confusing EMF (source) with terminal voltage (which drops with internal resistance)
- Faraday's law sign: Lenz's law gives the direction — induced current opposes the change in flux

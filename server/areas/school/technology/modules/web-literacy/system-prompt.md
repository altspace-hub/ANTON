# Web Literacy — Layer 3 Lesson Methodology
# Module: Web Literacy | Area: Technology | Tier: T2

## What You Are Teaching in This Session

Focus: **How the web works and how to be a skilled, critical user of it.**

Core topics:
- How websites are built (HTML = structure, CSS = style)
- How a URL, DNS, and browser work together
- Evaluating online sources: authority, accuracy, currency, purpose
- Search strategies: going beyond the first result
- Cookies, tracking, and data collection basics

## Teaching Methodology for Web Literacy

### The Core Question:
Every web literacy lesson starts from curiosity: "You use websites every day — have you ever wondered what's actually happening?" Use this as the hook.

### Sequencing:
1. **Start with something they use** — their favourite website, app, or social platform
2. **Lift the hood** — "Right-click → View Page Source. What do you see?" (Even if messy, the curiosity is valuable)
3. **Explain one concept clearly** — pick ONE thing per session (HTML tags, OR how DNS works, OR how to evaluate sources)
4. **Apply immediately** — "Now that you know this, let's look at [concrete example]"

### Source Evaluation — SIFT Model:
Teach **Stop, Investigate, Find better coverage, Trace claims**:
- Stop before sharing or believing
- Investigate the source (who runs this site?)
- Find better coverage (does anyone else report this?)
- Trace claims back to their origin

### Common Mistakes to Correct:
- "The first Google result is the most reliable" → Explain SEO and paid placement
- "I can spot fake news" → Most people can't — introduce lateral reading
- "If it looks professional it must be true" → Show polished misinformation examples

### For HTML/CSS Basics:
Do NOT teach syntax lists — teach purpose and exploration:
- What does this tag DO? (not: memorise these 50 tags)
- Let students edit live HTML in browser developer tools
- Small wins: "Change the heading colour" → "You just wrote CSS"

### Guided Questions to Use:
- "Who wrote this — and how do you know?"
- "What would this page look like without any CSS?"
- "If you were trying to mislead someone with this data, how would you present it?"

# Data Handling — Layer 3 Lesson Methodology
# Module: Data Handling | Area: Technology | Tier: T2

## What You Are Teaching in This Session

Focus: **Collecting, organising, analysing, and presenting data — and reading data critically.**

Core topics:
- Spreadsheet fundamentals (Google Sheets / Excel)
- Formulas: SUM, AVERAGE, COUNT, IF, basic VLOOKUP
- Data visualisation: choosing the right chart for the right data
- Collecting data: surveys, sampling, avoiding bias
- Reading data critically: misleading graphs, missing context, cherry-picking

## Teaching Methodology for Data Handling

### The Real-World Hook:
Students deal with data constantly — sports statistics, social media metrics, news charts, school grades. Start there: "Where did you see data presented recently? Did you trust it? Why?"

### Spreadsheet Teaching Approach:
Never teach features in isolation. Every feature is taught to solve a real problem:
- "You have 30 exam results. How do you find the class average?" → AVERAGE formula
- "You want to know how many students scored above 70%?" → COUNTIF
- "You want to highlight anyone below a threshold automatically?" → conditional formatting

Hands-on from minute one. Students should have a sheet open and be doing things, not watching.

### Chart Selection — The Most Common Mistakes:
Teach WHEN to use each:
- **Bar chart:** Comparing categories (not time trends)
- **Line chart:** Showing change over time (not comparing unrelated categories)
- **Pie chart:** Parts of a whole — only works if the parts add to 100% and there are fewer than 5 slices
- **Scatter plot:** Showing relationships between two variables (not for categories)

Show examples of wrong chart choices from real news articles. Ask: "What is misleading here?"

### Misleading Data Visualisation:
The classic examples (and why they work):
- Y-axis that doesn't start at zero (makes small changes look dramatic)
- 3D pie charts (distorts area perception)
- No sample size stated
- Correlation presented as causation

### Data Collection Activity:
Students design a simple survey → collect responses → analyse → present findings.
Teach sampling issues: "Is this group representative? Who is missing?"

### Critical Reading Framework:
For any chart or data claim:
1. Who collected this data — and who paid for the study?
2. What is the sample size?
3. What is the Y-axis doing?
4. What would make me trust or distrust this?

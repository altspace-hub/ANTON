# Coding Area Context

## Purpose
The Coding Area provides four tiers of AI-powered software development capabilities, from code review through to full professional project delivery.

## Tier Structure

### Tier 1: Code Review & Explain
Review existing code through multiple expert lenses: developer quality, security vulnerabilities, compliance concerns, product alignment, and architecture patterns. Supports paste, directory, and repository inputs. Includes diff-aware re-review and dependency/supply chain auditing.

### Tier 2: Script Lite
Generate single Python scripts from natural language descriptions. Guided questioning ensures the AI understands requirements before generating. Scripts can be previewed in a sandboxed environment with sample data.

### Tier 3: Script Medium
Generate complete applications (React SPA, HTML/CSS/JS, Python CLI, Node.js API) from natural language. Multi-file output with live preview. Iterative refinement supported.

### Tier 4: Coding Large — Professional Delivery
Full AI-led software development following a structured lifecycle:
- **Phase 0 — Codebase Onboarding**: Baseline assessment of existing code
- **Phase 1 — Discovery**: Multi-turn requirements gathering with cross-area expertise
- **Phase 2 — Architecture**: Design with expert panel review (security, compliance, product)
- **Phase 2b — Estimation**: Complexity sizing and cost estimation
- **Phase 3 — Release Planning**: Milestone-based release plans with acceptance criteria
- **Phase 4 — Implementation**: Task-by-task execution with plan→approve→execute→record cycle
- **Phase 5 — Testing**: Automated and manual test execution with regression tracking
- **Phase 6 — Operational Readiness**: Deployment checklists, monitoring, documentation

## Cross-Area Integration
The Coding Area integrates with all expert areas for review panels. Security reviews draw from Cybersecurity area context. Compliance reviews draw from FCP and Legal area contexts. Architecture reviews draw from Software Engineering area context.

## Quality Standards
- All code outputs are scored via the quality ratchet system
- Expert panel reviews use the endorse/flag/dissent verdict system
- Goal alignment checks compare current state against discovery commitments
- Technical debt is tracked and surfaced throughout the project lifecycle
- Cost tracking provides real-time visibility into API token consumption per phase

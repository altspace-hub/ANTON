Welcome to ANTON

This folder has everything needed to run ANTON on your computer — nothing else to install. Three steps and you're going.

Before you start

You need two things:

• A Windows 10 or 11 computer.
• An Anthropic API key — this is what lets ANTON think. Get one (it takes a minute) at console.anthropic.com. It looks like sk-ant-.... Keep it handy for step 3.

Getting started

1
Unzip this folder

If you haven't already, unzip the download somewhere easy to find — your Documents folder or the Desktop is perfect. Keep all the files together in the one folder.

2
Double-click Start ANTON (portable).bat

It's in this folder. A small black window will open — that's normal, it's ANTON starting up. Leave it open.

3
Paste your API key, then wait

The first time only, the window asks for your Anthropic API key — paste it in and press Enter. Then ANTON sets itself up. This takes a few minutes the first time — that's normal, just let it run. When it's ready, ANTON opens in your web browser by itself.

After the first time, it's instant. Just double-click the ANTON icon that was added to your desktop — or Start ANTON (portable).bat again.

Using and stopping ANTON

ANTON runs in your normal web browser. While you're using it, keep the small black window open — closing it stops ANTON.

To stop ANTON properly: close that black window, or double-click Stop ANTON (portable).bat.

Everything you do in ANTON stays on your own computer. Your documents never leave the machine — only the questions ANTON sends to Claude go out to the internet.

If something looks wrong

Windows says "Windows protected your PC"

That's Windows being cautious about a program it doesn't recognise — ANTON is safe. Click More info, then Run anyway.

My antivirus flagged something

Some antivirus tools are over-cautious with bundled programs they haven't seen before. Nothing here is harmful. If you're unsure, ask whoever gave you this folder.

The browser didn't open

Look at the black window — it shows a line like ANTON is running: http://localhost:3001 (the number may differ). Type that address into your web browser yourself.

It says a port is busy / it's using a different port

That's fine — ANTON automatically picks a free one and tells you the address in the window. Just use the address it shows.

It won't start at all

Read the messages in the black window — they say what went wrong. The most common cause is a mistyped API key; you can fix it by editing the .env file in this folder.

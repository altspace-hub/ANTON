Build status — an honest map

The ANTON suite is close to complete, but not uniformly. This page is the candid version: what is fully built, what is partial, what is stubbed, and what is still only specified. If another page makes a feature sound finished and you want to check, check here.

1How to read the labels

BUILT

Implemented, working, in day-to-day use. Safe to rely on.

PARTIAL

The core works; some paths are unfinished or in progress.

STUB

The shape exists; calls throw or return placeholders. Blocked.

SPEC

Designed and documented; not yet implemented.

2The critical-path blocker

⚠One dependency gates the payment rail

The FutureChain Rust core — specifically iso20022_pacs008.rs — has not yet been vendored into the repo. Until it is, the SDK's pacs008 builder cannot build, canonicalise, hash or sign a real PACS.008 message. Everything downstream waits on it: cryptographically signed payment records and real on-chain settlement.

The apps are deliberately built so this is not visible to users today — ANTON Pay and ANTON Comm assemble PACS.008 drafts as plain objects, populate them and show them in the ISO 20022 detail panel. Signing simply switches on when the SDK unstubs. See The payment flow for the full picture.

💡What this means in practice

You can use ANTON Local, all four phone apps, pairing, the mesh relay and the QR payment flow today — they are built. What is not yet real is the cryptographic signing and on-chain settlement of payments, and public cross-instance portal discovery. Those are honest gaps, not bugs.

5The 6-layer vision

ANTON is designed as six layers, each independently useful, each making the next more powerful. This is where the whole project stands against its own plan.

#LayerStatus
1Individual ANTON — pillars, modules, 7-layer promptsDONE
2Intelligent ANTON — knowledge atoms, pattern detection, predictions, calibrationMOSTLY DONE
3Network — Community, E2E messaging, contact hashes, trustBUILT
4Collaborative Intelligence — ANTON-to-ANTON via the Agent ProtocolIN PROGRESS
5Marketplace — .anton bundle trading, rating, discoveryNOT STARTED
6Economy — FutureChain payments, expertise as incomeNOT STARTED

The four phone apps and the payment rail are the first concrete steps into layers 4–6: Companion extends an instance to mobile, Comm carries the network peer-to-peer, and Business + Pay are the first working pieces of the economy.

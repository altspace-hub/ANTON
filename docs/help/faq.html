FAQ & troubleshooting

The questions that come up most often, and the fixes for the things that most often go wrong. Each answer links to the page with the full story.

1General

Is ANTON one app or several?

Several. One desktop workspace — ANTON Local — and four phone apps: Companion, Comm, Business and Pay. They share an identity model and a few protocols but install and run independently.

Does my data leave my machine?

ANTON is local-first. Documents and records stay on the device. The only things that leave are LLM API calls (from ANTON Local) and actions you explicitly take — sending a message, making a payment. The phone apps have no backend at all.

Which app should I use?

If you do expert knowledge work, ANTON Local. To reach your instance from a phone, Companion. For encrypted messaging and a wallet without an instance, Comm. To take payments, Business. To make payments, Pay.

💡Not sure something is finished?

Check the Build status page. It is the honest map of what is built, partial, stubbed or still spec.

2ANTON Local

What do I need to run it?

Node.js 22+, pnpm, PostgreSQL 16+, and an Anthropic API key. Ollama is optional (for knowledge memory). The full walkthrough is on Install & first run.

Do I have to use Claude?

No — Claude is the default and the most deeply integrated, but ANTON Local also supports OpenAI, Azure OpenAI, Gemini, Mistral and local Ollama models. Add the relevant key in .env and switch model per session. See Knowledge & prompts.

What is a pillar versus a module?

A pillar is a whole mode of intelligence you switch into (Work, Markets, Missions…). A module is one pre-tuned expert task inside the Work pillar. See The 12 pillars and Work.

How do I get good output the first time?

Trust the defaults — every module ships pre-tuned. Then pick the right knowledge source for the task, choose an output format before running, and raise the thinking level for harder problems.

3The phone apps

How does a phone connect to my ANTON Local?

Through the Ed25519 pairing ritual — the desktop shows a QR, the phone scans it, and a device certificate is issued. After that the phone reaches the instance either directly over HTTPS or through the mesh relay.

Does ANTON Comm need ANTON Local?

No. Comm is fully standalone — it creates its own identity and works peer-to-peer. Companion is the one that requires a paired instance.

Why is ANTON Comm only in English and Swedish?

Comm shipped its feature roadmap before a full translation pass. It currently has only English and Swedish locale catalogues, so other languages fall back to English. Pay and Business, by contrast, ship 38 languages. See Build status.

Can I run several of the apps on one phone?

Yes — each has its own application id and installs separately.

4Payments

How does a payment actually work?

ANTON Business builds a futurechain:pay QR; ANTON Pay or Comm scans it, shows the detail, runs the fraud check, and records the payment. The full flow is on The payment flow.

Are payments cryptographically signed and settled on-chain?

Not yet. PACS.008 drafts are assembled and shown today, but real signing and settlement are blocked on the FutureChain Rust core being vendored — see the critical-path blocker. The apps are built so signing switches on cleanly when that lands.

The fraud engine flagged my payment — did it block it?

No. The fraud engine is always advisory. It raises signals so you pause and think; the decision is always yours. A warning-level result asks you to confirm twice, nothing more.

I lost my phone — can I recover my wallet?

Only if you backed it up. The wallet key is created on-device and held in secure storage; without a backup it cannot be recovered. Treat it like cash and back up before changing phones or resetting the app.

5Troubleshooting

✓ Common fixes
  • Dev server won't start — check DATABASE_URL in .env and that PostgreSQL is running; re-run pnpm run db:init.
  • "Payment code expired" — QR codes expire after 15 minutes; ask the merchant for a fresh one.
  • Pairing QR rejected — the enrollment package lives only 60 seconds; generate a new one and scan promptly.
  • Phone can't reach the instance — confirm the instance is on the same LAN or has a public URL; otherwise use the mesh relay.
  • An old theme/accent persists — the phone apps store settings locally; clear app storage to return to defaults.
✕ Things to check first
  • Antivirus may flag a sideloaded debug APK as a false positive — it is unsigned, not malicious.
  • An LLM error mid-run usually means a missing or rate-limited API key — check .env.
  • If output looks thin, you may be on a low thinking level — raise it and re-run.
  • If a feature seems missing, it may be stubbed — confirm on Build status before assuming a bug.
⚠Still stuck?

The deepest source of truth is the code itself. CLAUDE.md at the repository root orients you; the relevant help page's "How it works" panels name the exact files. Press t on any page to open them all.
